# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |
| Unversioned 2018 code | No |

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository if it is enabled, or contact the owner through their GitHub profile. Do not include exploit details in a public issue.

## Scope

The application has no accounts, forms, sessions, cookies, or database connection. TLS, HSTS, and rate limiting are the responsibility of the deployment layer.
